# 未见 · AI作品展

一个轻量、强策展的 AI 视觉作品展原型。它不解释技术，只收藏让人想停下、收藏和分享的作品。

## 本地预览

在项目目录运行任意静态服务器，并将根目录指向 `dist/`。例如：

```powershell
npx serve dist
```

## 更新展品

编辑 `dist/app.js` 顶部的 `works` 数组。每件作品包含：

- `id`：唯一英文标识
- `title`：作品名称
- `line`：一句策展语
- `mood`：情绪分类
- `author`：作者
- `visual`：视觉样式类名
- `status`：授权或展示状态

当前八件展品均为原创程序化概念演示，不代表真实第三方作品。
